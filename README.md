# Железо — планировщик тренировок

Мобильное веб-приложение для планирования силовых тренировок на месяцы вперёд:
недели и дни, в каждой тренировке упражнения с подходами × повторами × весом.
Интерфейс на русском, веса в килограммах.

**Открыть:** https://vvvvoronenko75-cmd.github.io/zhelezo/

На телефоне откройте ссылку и добавьте страницу на главный экран — приложение
запускается как обычное, работает без интернета.

## Что умеет

- Программа на несколько месяцев с автоматическим ростом весов (линейная прогрессия)
- Отметка подходов в зале, таймер отдыха, тоннаж и время сессии
- Правка упражнений с переносом изменений на будущие тренировки — прогрессия сохраняется
- Календарь тренировок с типами и статусами, навигация по месяцам
- Прогресс: динамика весов, тоннаж по неделям, личные рекорды

## Как устроено

Три файла без сборки и зависимостей: `index.html`, `styles.css`, `app.js` (ванильный
JavaScript). Данные тренировок хранятся только в браузере вашего устройства
(`localStorage`) — никуда не отправляются, аккаунт не нужен. Офлайн обеспечивает
`sw.js`.

**Важно:** очистка данных браузера удалит историю тренировок. Синхронизации между
устройствами нет.

## Разработка

Любой статический сервер, например:

```bash
python -m http.server 8731
```

Исходная разработка ведётся в приватном репозитории `claude-work`
(`projects/gym-planner`); сюда попадает опубликованная версия.
